# Icons

Fakr-Updatr ships a set of systray / application icons with multiple style (color) variants.

Available variants (usable with the `TrayIconStyle` option in `fakr-updatr.conf`):

| Value | Icon (up to date) | Icon (updates available) |
| ----- | ----------------- | ------------------------ |
| `blue` | `fakr-updatr-blue` | `fakr-updatr_updates-available-blue` |
| `light` | `fakr-updatr-light` | `fakr-updatr_updates-available-light` |
| `dark` | `fakr-updatr-dark` | `fakr-updatr_updates-available-dark` |

The "updates available" variants also come with a colorblind-friendly `-cb` suffix (enabled with the `ColorblindMode` option).

`fakr-updatr_app-icon.svg` is the general application icon.
